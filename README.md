Contents

- Blocks
- Items
- Maps
- Paintings
- Entities
- Particles
- Armor Trims
- UI/UX Textures
- Environment
- Models

- Other texture resources

How to Use

1. Download the ZIP containing the textures you need.
2. Extract the archive.
3. Browse the folders and use the textures as references for your own resource packs.
